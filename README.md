# Femtosecond Pulsed Laser Model (for Ansys Lumerical FDTD)

A custom material model for Ansys Lumerical FDTD designed to accurately model femtosecond pulsed laser free carrier densities. This model includes:
- Single-photon absorption (SPA)
- Two-photon absorption (TPA)
- Free carrier absorption (FCA)
- Free carrier refraction (FCR)
- Kerr effect
